🚀 GitHub 上架全攻略

從安裝 Git 到首次推送，新手完全指南（離線也能閱讀）

1前置準備：你需要什麼？

跑通這個教學，你只需要一台電腦（Windows / Mac / Linux 皆可）與一個能上網的瀏覽器。全部步驟完成後，你的程式碼就會出現在 GitHub 上，任何人都能看到（或設為私人）。

💻電腦Windows、macOS 或 Linux
🌐網路註冊 GitHub 與推送時需要連線
📁一個專案哪怕只有一個 index.html 也可以

2Step 1：安裝 Git

Git 是一種「版本控制軟體」，用來記錄你檔案的每一次變更，並能上傳到 GitHub。

什麼是 Git 與 GitHub 的關係？
Git = 本地安裝的版本控制工具（裝在你的電腦）
GitHub = 在雲端存放 Git 專案的網站（像是程式碼的 Dropbox + 社交網路）

Windows 安裝

  1. 前往 git-scm.com 下載 Windows 版安裝程式。
  2. 執行下載的 .exe，一路點 Next 即可（預設設定對新手來說沒問題）。
  3. 安裝完成後，在開始選單搜尋 Git Bash 並開啟。

Mac 安裝 macOS

最快的方式是使用 Homebrew：

brew install git

如果你沒有 Homebrew，也可以在終端機直接輸入 git，系統會提示你安裝 Xcode 命令列工具，照提示安裝即可。

Linux 安裝 Linux

sudo apt update
sudo apt install git

（以 Ubuntu / Debian 為例，其他發行版請對應套件管理器安裝。）

驗證安裝是否成功：在終端機（Git Bash / 終端機 / 命令提示字元）輸入：
git --version
如果看到類似 git version 2.xx.x 就代表安裝成功。

3Step 2：註冊 GitHub 帳號

  1. 開啟瀏覽器，前往 github.com。
  2. 點擊右上角的 Sign up（註冊）。
  3. 依序輸入你的電子郵件、設定密碼、使用者名稱（username）。
  4. 完成驗證碼與電子郵件確認，帳號就建立完成了。
使用者名稱小建議：這會出現在你的專案網址中（例如 github.com/你的名字/專案名），建議用英文或數字，避免特殊符號與空白。

4Step 3：設定 Git 基本資訊

安裝完 Git 後，先告訴 Git「你是誰」，這樣你之後每次提交（commit）都會記錄作者。

git config --global user.name "你的名字"
git config --global user.email "你的email@example.com"
複製指令

確認設定是否生效：

git config --global --list
你應該會看到剛剛輸入的 user.name 與 user.email。

5Step 4：在 GitHub 建立儲存庫（Repository）

  1. 登入 GitHub 後，點擊右上角你的個人照片，選擇 Your repositories。
  2. 點擊綠色的 New（或 + → New repository）按鈕。
  3. 填寫資訊：
    • Repository name：專案名稱，例如 my-first-site
    • Description（選填）：簡單描述，例如 我的第一個 GitHub 上架專案
    • Public / Private：選擇公開或私人，新手建議先選 Public，這樣比較方便分享。
  4. 重要：不要勾選「Add a README file」與「Initialize this repository with...」等選項，因為我們要從本機把專案推上去，勾選這些會造成後續衝突。
  5. 點擊 Create repository 建立。
建立完成後，GitHub 會顯示一個網址，例如：
https://github.com/你的使用者名稱/my-first-site.git
請把這個網址複製起來，稍後會用到。

6Step 5：在電腦上建立專案並 Commit

現在我們在電腦上建立一個資料夾，放入你要上架的檔案。

  1. 在桌面或文件資料夾建立一個資料夾，例如 my-first-site。
  2. 進入該資料夾，建立一個簡單的 index.html，內容隨便寫，例如：
<!DOCTYPE html>
<html lang="zh-TW">
<head>
  <meta charset="UTF-8">
  <title>我的首頁</title>
</head>
<body>
  <h1>你好，GitHub！</h1>
  <p>這是我第一次上架到 GitHub 的網頁。</p>
</body>
</html>
  1. 開啟終端機（Windows 請用 Git Bash），進入該資料夾：
cd ~/Desktop/my-first-site
如果不確定路徑，可以在檔案總管（Windows）或 Finder（Mac）中，對該資料夾按右鍵選擇「在此開啟終端機」。
  1. 初始化 Git 儲存庫：
git init
  1. 把所有檔案加入「暫存區」：
git add .
  1. 建立第一次提交（Commit）：
git commit -m "初始提交：上架至 GitHub"

7Step 6：連結 GitHub 並 Push 上架

這是最關鍵的一步：把本機的專案推到 GitHub 上。

  1. 將本地儲存庫與遠端 GitHub 儲存庫連結（把 你的使用者名稱 與 my-first-site 換成你自己的）：
git remote add origin https://github.com/你的使用者名稱/my-first-site.git
複製指令
  1. 把分支命名為 main（GitHub 預設主分支）：
git branch -M main
  1. 推送（Push）到 GitHub：
git push -u origin main
⚠ 關於帳號密碼（新手常卡關）：
GitHub 已經停止直接用「帳號 + 密碼」登入 Git 操作。當終端機要求輸入使用者名稱與密碼時：
  • 使用者名稱：輸入你的 GitHub 使用者名稱。
  • 密碼：請貼上你的 Personal Access Token (PAT)，而不是 GitHub 登入密碼。輸入時不會顯示任何字元（正常現象），貼上後按 Enter 即可。
如何建立 Personal Access Token（PAT）：
1. 在 GitHub 點擊右上角照片 → Settings
2. 左側最下方 → Developer settings → Personal access tokens → Tokens (classic)
3. 點擊 Generate new token (classic)
4. 在 repo 欄位打勾（代表允許上傳程式碼）
5. 最下方點擊 Generate token
6. 立刻複製 顯示出來的 token（離開頁面就看不到了）
7. 貼到終端機的「密碼」欄位
成功後，終端機會顯示類似這樣的訊息：
Enumerating objects: 3, done.
Counting objects: 100% (3/3), done.
Writing objects: 100% (3/3), 250 bytes | 250.00 KiB/s, done.
Total 3 (delta 0), reused 0 (delta 0), pack-reused 0
To https://github.com/你的使用者名稱/my-first-site.git
 * [new branch]      main -> main
Branch 'main' set up to track remote branch 'main' from 'origin'.

8Step 7：確認上架成功

  1. 回到 GitHub 網頁，刷新你的儲存庫頁面。
  2. 你應該會看到剛才上傳的 index.html 與其他檔案。
  3. 點擊檔案名稱就能在瀏覽器中直接查看內容。
恭喜！你的專案已經上架 GitHub 了。
專案網址格式：https://github.com/你的使用者名稱/my-first-site

常見問題 Q&A

Q1. 終端機顯示「git: command not found」怎麼辦？

代表 Git 沒安裝成功或沒加入系統路徑。請回到 Step 1 重新安裝，Windows 使用者請務必使用 Git Bash 執行指令。

Q2. Push 時一直要求輸入使用者名稱與密碼，輸入 GitHub 密碼卻失敗？

因為 GitHub 不再接受直接用網頁登入密碼進行 Git 操作，請使用 Personal Access Token (PAT)（見 Step 6 的警告方塊）。

Q3. 出現「remote origin already exists」？

代表這個遠端連結已經加過了。你可以先移除再重新加入：

git remote remove origin
git remote add origin https://github.com/你的使用者名稱/my-first-site.git

Q4. 我想把專案設為私人，別人看不到怎麼辦？

在 GitHub 儲存庫頁面點擊 Settings → Danger Zone → Change visibility，即可切換公開/私人。

Q5. 之後修改了檔案，要怎麼再次上傳？

進入該資料夾後，依序執行這三個指令即可：

git add .
git commit -m "更新內容"
git push
因為你之前已經執行過 git push -u origin main，之後直接打 git push 就夠了，不需要再寫分支名稱。

後續建議

  • 建立 .gitignore 檔案，告訴 Git 哪些檔案不要上傳（例如系統暫存檔、密碼設定檔等）。
  • 學習 GitHub Pages：可以免費把你的靜態網站上架成實際網址（例如 你的名字.github.io）。
  • 嘗試 Pull Request 與 Issue，與其他開發者協作。
